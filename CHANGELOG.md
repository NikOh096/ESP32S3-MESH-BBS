# Release notes

## 0.5.0 — September 25, 2026

- Separate MeshCore BBS preview targeting companion-v1.17.1 with the shared owner,
  thread, queue, rule, expiry and moderation interface.
- Four ESP32-S3 profiles per protocol: N16R8/N8R8 and GPIO48/GPIO38.
- Browser installer with chip/memory checks, integrity and flash verification,
  progress, recovery instructions and preserved BBS storage.
- Android: one Connect action, PIN guidance, conversation-focused Home, selected
  tab states, and a searchable catalog of 205 upstream model/variant records.
- Discovery distinguishes protocol candidates; hardware details appear after
  pairing. MeshCore hides unsupported hop controls.
- Persistent MeshCore full-key aliases and ambiguous-prefix rejection. Smaller
  radio packets keep list entries intact.
- Public setup, privacy, security, contribution and compatibility documentation.

MeshCore, extra hardware layouts and the new phone UI remain **pre-release** until
physical acceptance tests pass. See [validation](docs/VALIDATION.md).
