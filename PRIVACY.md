# Privacy

MESHBBS has no accounts, advertising, analytics or cloud message service.

- Posts, comments, identifiers, settings and counters live on the BBS board.
  Radio visitors can read public threads.
- Android keeps the owner secret protected by Android Keystore, with local board
  and notification preferences. Notifications require nearby Bluetooth; Android
  lock-screen previews can be controlled in system settings.
- Activity logs can contain message text and node IDs. Review a copied log before
  sharing it publicly.
- The installer talks to USB locally and does not upload board contents or keys.
  Its host receives ordinary requests for the page, firmware and APK. There are
  no third-party analytics scripts.
- Bluetooth advertisements and radio identifiers are observable. Administration
  is protected; the board is not invisible.

Deleting a thread cannot recall copies already received by visitors. Normal updates
retain data. A full flash erase removes posts, settings and owner enrollment.
